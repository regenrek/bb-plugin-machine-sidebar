# German terminology

Use these terms consistently in the German sidebar strings:

| English | German |
| --- | --- |
| Thread / sub-thread | Gespräch / Untergespräch |
| Machine / project | Maschine / Projekt |
| Git worktree | Git-Worktree (branch label: Git-Worktree-Branch) |
| Working folder | Arbeitsordner |
| Pin / unpin | Anpinnen / Nicht mehr anpinnen |
| Mark active / inactive | Als aktiv markieren / Als inaktiv markieren |
| Mark project active / inactive | Projekt als aktiv markieren / Projekt als inaktiv markieren |
| Mark all active | Alle als aktiv markieren |
| Days / hours / minutes | Tg. / Std. / Min. (for example, 2 Tg. 3 Std.) |

Keep Channels, Worker, Tool, Branch, Workflow, Plugin, Sidebar, Tag and Bug in
English, including German compound words such as Tool-Aufruf and Tag-Farben.
Keep product and provider names such as bb, Farcall and Codex unchanged.
Channels is reserved terminology; the Machine Sidebar has no Channels UI.

Labels and slot titles registered with bb stay English because the host does
not update them with the plugin's language setting.
